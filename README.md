## 🔥 Features

- 🎯 **AI-Powered Generation** — Uses Groq LLaMA 3.3 70B to generate high-quality content
- 🇮🇳 **Hinglish & English** — Switch between Hinglish (Hindi in Roman script) and English
- 👩👦 **Gender-Specific** — Tailor lines for girls, boys, or random
- 💌 **Crush Name Shayari** — Generates shayari with your crush's name woven in naturally
- 😍 **Crush Name Flirting** — Personalized flirting lines featuring their name
- 💬 **Message Reply** — Paste their message and get a witty, flirty reply
- 😉 **Flirting Reply** — Generate engaging flirty conversation starters
- 🔥 **Random Flirting Line** — Fresh, creative pickup lines on demand
- 📜 **Shayari** — Beautiful romantic shayari
- 😢 **Sad Shayari** — Emotional shayari about love and longing
- 😂 **Funny Shayari** — Clever and humorous shayari
- 💪 **Motivation Shayari** — Inspiring and uplifting shayari
- ✨ **Random Shayari** — Mix of all shayari styles
- 📋 **One-Click Copy** — Copy generated content to clipboard instantly
- 💬 **Auto Reply** — Generate a reply to the AI's own message
- 💾 **Remembers Settings** — Your language, gender & category preferences are saved

## 🛠️ Setup & Deployment

### Option 1: Drag & Drop (Fastest)

1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag the entire `xflirting-website` folder onto the page
3. Your site is live! ✨

### Option 2: Netlify CLI

```bash
npm install -g netlify-cli
cd xflirting-website
netlify login
netlify deploy --prod --dir .
```

### Option 3: GitHub + Netlify

1. Push this folder to a GitHub repository
2. Go to [app.netlify.com](https://app.netlify.com)
3. Click **"Add new site"** → **"Import an existing project"**
4. Connect your GitHub repo
5. Set **Publish directory** to `.`
6. Click **Deploy**
